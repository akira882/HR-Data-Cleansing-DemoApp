# スプレッドシート数式ガイド ― XLOOKUP と COUNTIF しか知らない人のための構文解説

> 練習用ブック（`python tools/generate_ab_sample_data.py --xlsx` で作る `training_workbook.xlsx`）で、
> **数式を1つずつ理解しながら** 突合を最後までやり切るためのガイドです。
> ブックの中にも同じ内容が「関数ドリル」「手順」シートとして入っているので、ブックだけでも進められます。

---

## 0. この教材の数式は検証済みです

このガイドとブックの「手順」シートに載せた数式は、すべて **実際に表計算ソフトで計算させて検証** しています。

- 練習データ（約1,000名・最も難しいレベル3を含む）の全行に、手順どおりの数式を入れて計算した
- その結果を提出シートに書き出して採点し、**誤統合0件・差異をすべて検出・ノイズ0件（満点）** になることを確認した
- 「関数ドリル」シートの18問は、答えの例を入れると全問「○」になることを確認した
- この検証は自動テスト（`tests/test_spreadsheet_formulas.py`）になっていて、教材を変更するたびに再確認される

> 検証に使った表計算ソフト（LibreOffice）は XLOOKUP に対応していない版のため、検証のときだけ、
> 同じ動きをする `IFERROR(INDEX(返す範囲, MATCH(探す値, 探す範囲, 0)), 見つからないとき)` に置き換えて計算しています。
> XLOOKUP は Excel 2021 / Microsoft 365 / Googleスプレッドシートで使えます。

## 1. 数式の基本ルール（最初に読む）

| ルール | 説明 | 例 |
|---|---|---|
| **= で始める** | セルに `=` から入力すると数式になる | `=LOWER(L2)` |
| **文字は "" で囲む** | 数式の中の文字は二重引用符で囲む。`""`（中身なし）は「空欄」 | `"対象"`、`""` |
| **"1" と 1 は別物** | 受領データは文字列で入っているので、比べるときは `"1"` と書く | `G2="1"`（○） `G2=1`（×） |
| **行番号は自動でずれる** | 2行目に `=LOWER(L2)` を入れて下にコピーすると、3行目は `=LOWER(L3)` になる | 右下の■をダブルクリック |
| **別のシートは「シート名!」** | 別シートの列全体は `シート名!列:列` | `A_work!A:A` |
| **入れ子は内側から読む** | `SUBSTITUTE(SUBSTITUTE(C2," ",""),"　","")` は、内側（半角空白を消す）→ 外側（全角空白を消す）の順に動く | — |
| **長い数式は列を分ける** | 途中の結果を別の列に出すと、どこで間違えたかがすぐ分かる | 日付の変換（段階3） |

## 2. この教材で使う関数

あなたが知っている XLOOKUP と COUNTIF に加えて、12個を使います。どれも引数は2〜4個です。

| 関数 | 構文 | 何をするか | 例 | 結果 |
|---|---|---|---|---|
| **XLOOKUP** | `XLOOKUP(探す値, 探す範囲, 返す範囲, 見つからないとき)` | 表から値を探して、同じ行の別の列を返す | `=XLOOKUP("情シス",J:J,K:K,"★未登録")` | 14000000 |
| **COUNTIF** | `COUNTIF(範囲, 条件)` | 範囲の中で条件に一致するセルを数える | `=COUNTIF(M:M,"000123")` | 2 |
| **LOWER** | `LOWER(文字列)` | 英字を小文字にする | `=LOWER("Sato@Example.co.jp")` | sato@example.co.jp |
| **SUBSTITUTE** | `SUBSTITUTE(文字列, 探す文字, 置き換える文字)` | 文字を置き換える。置き換える文字を "" にすると消せる | `=SUBSTITUTE("佐藤 翔"," ","")` | 佐藤翔 |
| **&** | `文字列1 & 文字列2` | 文字列をつなぐ（関数ではなく記号） | `="佐藤"&"翔"` | 佐藤翔 |
| **LEFT** | `LEFT(文字列, 文字数)` | 左から指定した文字数を取り出す | `=LEFT("20260501",4)` | 2026 |
| **RIGHT** | `RIGHT(文字列, 文字数)` | 右から指定した文字数を取り出す | `=RIGHT("000000881",6)` | 000881 |
| **MID** | `MID(文字列, 開始位置, 文字数)` | 途中から指定した文字数を取り出す | `=MID("20260501",5,2)` | 05 |
| **FIND** | `FIND(探す文字, 文字列)` | 探す文字が何文字目にあるかを返す | `=FIND(".","H30.4.1")` | 4 |
| **VALUE** | `VALUE(文字列)` | 数字の文字列を数値にする | `=VALUE("30")` | 30（数値） |
| **IF** | `IF(条件, 真のとき, 偽のとき)` | 条件によって結果を変える | `=IF(A2="","空欄","あり")` | 空欄 または あり |
| **AND / OR** | `AND(条件1, 条件2, …) / OR(条件1, 条件2, …)` | AND はすべて満たすとき、OR はどれか1つ満たすときに TRUE | `=OR("2"="1","2"="2")` | TRUE |
| **DATE** | `DATE(年, 月, 日)` | 年・月・日から日付を作る | `=DATE(2026,5,1)` | 2026/5/1（日付） |
| **DATEVALUE** | `DATEVALUE(日付の文字列)` | 日付に見える文字列を日付にする | `=DATEVALUE("2026-5-1")` | 2026/5/1（日付） |

## 3. 関数ドリル（ブックの「関数ドリル」シート）

本番の作業に入る前に、1関数ずつ練習します。**G列に数式を書くと、H列に ○ か × が出ます。** 詰まったら、N列の「答えの例」を見ます。

| No | 関数 | やりたいこと | 構文 |
|---|---|---|---|
| 1 | LOWER | メールアドレスを小文字にする | `LOWER(文字列)` |
| 2 | SUBSTITUTE | 半角空白を消す | `SUBSTITUTE(文字列, 探す文字, 置き換える文字)` |
| 3 | SUBSTITUTE | 全角空白を消す | `SUBSTITUTE(文字列, "　", "")` |
| 4 | SUBSTITUTE×2 | 半角と全角の空白を両方消す（入れ子） | `SUBSTITUTE(SUBSTITUTE(文字列, 半角, ""), 全角, "")` |
| 5 | SUBSTITUTE | 異体字を一般的な字にする | `SUBSTITUTE(文字列, "髙", "高")` |
| 6 | & | 姓と名をつなぐ | `文字列1 & 文字列2` |
| 7 | RIGHT と & | 社員番号を6桁にそろえる | `RIGHT("000000" & 文字列, 6)` |
| 8 | IF | 空欄なら「空欄」、そうでなければ「あり」 | `IF(条件, 真のとき, 偽のとき)` |
| 9 | LEFT | YYYYMMDD から年を取り出す | `LEFT(文字列, 文字数)` |
| 10 | MID | YYYYMMDD から月を取り出す | `MID(文字列, 開始位置, 文字数)` |
| 11 | DATE | YYYYMMDD を日付にする | `DATE(年, 月, 日)` |
| 12 | IF と OR | 在籍(1)か休職(2)なら「在籍扱い」 | `IF(OR(条件1, 条件2), 真, 偽)` |
| 13 | IF と AND | 在籍(1)かつ役員(00)でなければ「対象」 | `IF(AND(条件1, 条件2), 真, 偽)` |
| 14 | XLOOKUP | 部署名を組織コードに変換する（右の表を使う） | `XLOOKUP(探す値, 探す範囲, 返す範囲, 見つからないとき)` |
| 15 | XLOOKUP | 表にない部署名のときは ★未登録 | `4つ目の引数が「見つからないとき」` |
| 16 | COUNTIF | 一覧（M列）に同じ社員番号が何回出るか | `COUNTIF(範囲, 条件)` |
| 17 | 日付の比較 | 利用開始日が入社日の7日前〜入社日なら「許容内」 | `AND(開始日<=入社日, 開始日>=入社日-7)` |
| 18 | FIND と MID | 和暦 H30.4.1 の「30」を取り出す | `MID(文字列, 2, FIND(".", 文字列)-2)` |

> 💡 **全問 ○ になってから** 次に進んでください。ここで使う関数が、本番の数式の部品です。

## 4. 本番の手順（ブックの「手順」シート）

A_work・B_work の黄色の列に、上から順に数式を入れていきます。各列について、

1. **何をするか** を読む
2. **使う関数** を見て、自分で数式を書いてみる
3. 書けなかったら「答えの数式」を開き、**構文の読み方** を読んでから入力する（コピーより、読みながら打つほうが身につく）
4. 何行か目で見て、思ったとおりの値になっているか確かめる

### 段階1　Aの比較用の列を作る（A_work M〜Q列）

まず、正とするAの側に「比べるための列」を作ります。原本の列は触りません。

#### A_work M列「氏名キー」

- **何をするか**：姓と名をつなげ、空白をなくし、異体字（髙・﨑・齋・邉）を一般的な字に寄せた「比較用の氏名」を作る
- **使う関数**：SUBSTITUTE、&
- **注意**：原本の氏名（B列・C列）は書き換えない。比較のためだけの列を新しく作る

<details><summary>答えの数式と、構文の読み方</summary>

```text
=SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(B2&C2," ",""),"　",""),"髙","高"),"﨑","崎"),"齋","斎"),"邉","辺")
```

① B2&C2 で姓と名をつなぐ → ② 内側の SUBSTITUTE 2つで半角・全角の空白を消す → ③ 外側の SUBSTITUTE 4つで異体字を1字ずつ置き換える。SUBSTITUTE(文字列, 探す文字, 置き換える文字)

</details>

#### A_work N列「メールキー」

- **何をするか**：メールアドレスを小文字にそろえる（大文字・小文字の違いで一致しなくなるのを防ぐ）
- **使う関数**：LOWER

<details><summary>答えの数式と、構文の読み方</summary>

```text
=LOWER(L2)
```

LOWER(文字列) は、英字をすべて小文字にする

</details>

#### A_work O列「突合対象」

- **何をするか**：突合仕様の母集団（在籍・休職、役員でない、出向中でない）に当てはまるかを判定する
- **使う関数**：IF、AND、OR
- **注意**：受領データは文字列なので "1" のように二重引用符で囲んで比べる。G{r}=1 と書くと一致しない

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(AND(OR(G2="1",G2="2"),H2<>"00",K2="0"),"対象","対象外")
```

① OR(G="1", G="2") で在籍か休職 → ② AND(①, H<>"00", K="0") で3条件すべて → ③ IF(条件, 真のとき, 偽のとき)。<> は「等しくない」

</details>

#### A_work P列「メール|対象」

- **何をするか**：「メールキー」と「突合対象」をつないだ検索用の値を作る（例: sho.sato@example.co.jp|対象）
- **使う関数**：&
- **注意**：区切りの | は、メールアドレスに含まれない文字なら何でもよい

<details><summary>答えの数式と、構文の読み方</summary>

```text
=N2&"|"&O2
```

& は文字列をつなぐ記号。XLOOKUP は1つの値でしか探せないので、2つの条件をつないで1つにする

</details>

#### A_work Q列「入社日(日付)」

- **何をするか**：YYYYMMDD 形式の文字列（20260501）を日付に変換する
- **使う関数**：DATE、LEFT、MID、RIGHT
- **注意**：結果が 46143 のような数字で表示されたら、セルの表示形式を「日付」にする（中身は同じ）

<details><summary>答えの数式と、構文の読み方</summary>

```text
=DATE(LEFT(E2,4),MID(E2,5,2),RIGHT(E2,2))
```

LEFT(文字列, 4) で先頭4文字=年、MID(文字列, 5, 2) で5文字目から2文字=月、RIGHT(文字列, 2) で末尾2文字=日。DATE(年, 月, 日) で日付にする

</details>

### 段階2　Bの比較用の列を作る（B_work I〜O列）

Bの側も、Aと同じ規則で比較用の列を作ります。M列・O列で ★未登録 が出たら、変換表（map_dept・map_type）に1行足します。

#### B_work I列「社員番号キー」

- **何をするか**：社員番号を6桁にそろえる（先頭ゼロが消えた 881 → 000881）。空欄は空欄のまま
- **使う関数**：IF、RIGHT、&
- **注意**：TEXT(B,"000000") でもよいが、Googleスプレッドシートでは文字列に効かないことがあるため、この書き方にしている

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(B2="","",RIGHT("000000"&B2,6))
```

① "000000"&B で先頭に0を6個つける（881 → 000000881）→ ② RIGHT(…, 6) で右から6文字を取る → ③ IF(B="", "", …) で空欄のときは何もしない

</details>

#### B_work J列「氏名キー」

- **何をするか**：A_work の氏名キーと同じ規則で、Bの氏名から比較用の氏名を作る
- **使う関数**：SUBSTITUTE
- **注意**：AとBで正規化の規則が1つでも違うと、同じ人が「差異あり」になる

<details><summary>答えの数式と、構文の読み方</summary>

```text
=SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(C2," ",""),"　",""),"髙","高"),"﨑","崎"),"齋","斎"),"邉","辺")
```

A_work の M列と同じ。違いは、Bは姓と名が1つのセル（C列）に入っていること

</details>

#### B_work K列「メールキー」

- **何をするか**：メールアドレスを小文字にそろえる
- **使う関数**：LOWER

<details><summary>答えの数式と、構文の読み方</summary>

```text
=LOWER(H2)
```

A_work の N列と同じ

</details>

#### B_work L列「部署キー」

- **何をするか**：部署名から半角・全角の空白をなくす（「東京工場　製造課」→「東京工場製造課」）
- **使う関数**：SUBSTITUTE
- **注意**：TRIM は前後の空白しか消さず、全角空白の扱いもソフトによって違うので使わない

<details><summary>答えの数式と、構文の読み方</summary>

```text
=SUBSTITUTE(SUBSTITUTE(D2," ",""),"　","")
```

SUBSTITUTE を2つ重ねる。内側で半角空白、外側で全角空白を消す

</details>

#### B_work M列「組織コード」

- **何をするか**：部署キーを変換表（map_dept）で組織コードに変換する。変換表にない部署名は ★未登録 と表示する
- **使う関数**：XLOOKUP
- **注意**：★未登録 が出たら止まって調べ、変換表に1行足す。推測で埋めない。COUNTIF(M:M,"★未登録") で残数を数えられる

<details><summary>答えの数式と、構文の読み方</summary>

```text
=XLOOKUP(L2,map_dept!A:A,map_dept!B:B,"★未登録")
```

XLOOKUP(探す値, 探す範囲, 返す範囲, 見つからないとき) 。map_dept のA列から探し、同じ行のB列を返す

</details>

#### B_work N列「雇用形態キー」

- **何をするか**：雇用形態ラベルから空白をなくす
- **使う関数**：SUBSTITUTE

<details><summary>答えの数式と、構文の読み方</summary>

```text
=SUBSTITUTE(SUBSTITUTE(E2," ",""),"　","")
```

L列と同じ

</details>

#### B_work O列「雇用区分コード」

- **何をするか**：雇用形態ラベルを変換表（map_type）でコード（01 など）に変換する
- **使う関数**：IF、XLOOKUP
- **注意**：変換表のコードは「01」のように文字列で入れる（数値の 1 にすると A の "01" と一致しない）

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(N2="","",XLOOKUP(N2,map_type!A:A,map_type!B:B,"★未登録"))
```

空欄なら空欄、そうでなければ XLOOKUP。M列と同じ形

</details>

### 段階3　Bの日付をそろえる（B_work P〜R列）

Bの利用開始日は「2026/5/1」「2018-04-01」「H30.4.1」が混ざっています。1つの数式で全部やろうとせず、途中の結果を列に出します。

#### B_work P列「元号」

- **何をするか**：利用開始日が和暦（H30.4.1 / R2.4.1）なら元号の1文字を取り出す
- **使う関数**：IF、OR、LEFT

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(OR(LEFT(F2,1)="H",LEFT(F2,1)="R"),LEFT(F2,1),"")
```

LEFT(文字列, 1) で先頭1文字。それが H か R なら、その文字を返す

</details>

#### B_work Q列「西暦年(和暦のみ)」

- **何をするか**：和暦の年を西暦に直す（平成30年 → 1988+30 = 2018、令和2年 → 2018+2 = 2020）
- **使う関数**：IF、VALUE、MID、FIND

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(P2="","",IF(P2="H",1988,2018)+VALUE(MID(F2,2,FIND(".",F2)-2)))
```

① FIND(".", F) で最初の . の位置（H30.4.1 なら4）→ ② MID(F, 2, 4-2) で2文字目から2文字="30" → ③ VALUE で数値の30に → ④ 平成なら1988、令和なら2018を足す

</details>

#### B_work R列「利用開始日(日付)」

- **何をするか**：利用開始日（2026/5/1・2018-04-01・H30.4.1 が混在）をすべて日付に変換する
- **使う関数**：IF、DATEVALUE、SUBSTITUTE、MID、FIND、&
- **注意**：長い数式は、P列・Q列のように途中の結果を別の列に出すと、どこで間違えたか分かりやすい

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(P2="",DATEVALUE(SUBSTITUTE(F2,"/","-")),DATEVALUE(Q2&"-"&SUBSTITUTE(MID(F2,FIND(".",F2)+1,10),".","-")))
```

和暦でないとき: / を - に置き換えて DATEVALUE（文字列→日付）。和暦のとき: 最初の . より後ろ（4.1）を取り出して . を - に置き換え、Q列の西暦年とつなぐ（2018-4-1）→ DATEVALUE

</details>

### 段階4　同じ人を見つける＝名寄せ（B_work S〜X列）

ここが一番大事な段階です。キーの優先順位（社員番号 → メール）を、列ごとに1つずつ作ってから、W列で結合先を決めます。

#### B_work S列「候補①社員番号」

- **何をするか**：社員番号キーでAの社員を探す（名寄せの第1キー）
- **使う関数**：IF、XLOOKUP

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(I2="","",XLOOKUP(I2,A_work!A:A,A_work!A:A,""))
```

XLOOKUP で A_work のA列（社員番号）から探し、見つかればその社員番号を返す。なければ空欄

</details>

#### B_work T列「候補①の在籍区分」

- **何をするか**：候補①の社員の在籍区分（1在籍・2休職・3退職）を取ってくる
- **使う関数**：IF、XLOOKUP

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(S2="","",XLOOKUP(S2,A_work!A:A,A_work!G:G,""))
```

返す範囲を A_work!G:G（在籍区分）にした XLOOKUP

</details>

#### B_work U列「候補②メール(突合対象)」

- **何をするか**：メールアドレスで、突合対象（在籍・休職）の社員を探す（名寄せの第2キー）
- **使う関数**：XLOOKUP、&

<details><summary>答えの数式と、構文の読み方</summary>

```text
=XLOOKUP(K2&"|対象",A_work!P:P,A_work!A:A,"")
```

K&"|対象" で A_work の P列と同じ形の値を作って探す。再雇用者のように同じメールが2行あっても、在籍中のほうが見つかる

</details>

#### B_work V列「候補③メール(全員)」

- **何をするか**：メールアドレスで、退職者も含めた全員から探す
- **使う関数**：XLOOKUP

<details><summary>答えの数式と、構文の読み方</summary>

```text
=XLOOKUP(K2,A_work!N:N,A_work!A:A,"")
```

A_work の N列（メールキー）から探す

</details>

#### B_work W列「結合先」

- **何をするか**：このBアカウントを結合するAの社員番号を決める
- **使う関数**：IF、AND
- **注意**：氏名では結合しない（同姓同名の別人がいる）。結合先が空欄のアカウントは「Bのみ」になる

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(S2<>"",IF(AND(T2="3",G2="1",U2<>"",U2<>S2),U2,S2),IF(U2<>"",U2,V2))
```

社員番号で見つかった（S が空でない）とき: 「その社員は退職(3)・Bは有効(1)・同じメールの在籍者が別にいる」なら再雇用とみなして U、そうでなければ S。社員番号で見つからないとき: U、それもなければ V

</details>

#### B_work X列「結合方法」

- **何をするか**：どのキーで結合したかを記録する（あとで確認するため）
- **使う関数**：IF

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(W2="","なし",IF(W2=S2,"社員番号","メール"))
```

W と S が同じなら社員番号、違えばメール

</details>

### 段階5　差異を判定する（B_work Y〜AF列）

結合先が決まったら、項目ごとに比べます。差異があれば、提出用の item の値（name・org など）がそのまま入るようにしています。

#### B_work Y列「Aの入社日」

- **何をするか**：結合先の社員の入社日（日付）を取ってくる
- **使う関数**：IF、XLOOKUP
- **注意**：日付が数字で表示されたら、表示形式を「日付」にする

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(W2="","",XLOOKUP(W2,A_work!A:A,A_work!Q:Q,""))
```

返す範囲を A_work!Q:Q（入社日(日付)）にした XLOOKUP

</details>

#### B_work Z列「差異_氏名」

- **何をするか**：Bの氏名キーと、結合先のAの氏名キーを比べる。違えば name
- **使う関数**：IF、XLOOKUP

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(W2="","",IF(J2=XLOOKUP(W2,A_work!A:A,A_work!M:M,""),"","name"))
```

XLOOKUP で結合先の氏名キーを取ってきて、= で比べる。等しければ空欄、違えば "name"

</details>

#### B_work AA列「差異_所属」

- **何をするか**：Bの組織コード（変換後）と、Aの組織コードを比べる。違えば org
- **使う関数**：IF、XLOOKUP

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(W2="","",IF(M2=XLOOKUP(W2,A_work!A:A,A_work!I:I,""),"","org"))
```

Z列と同じ形。比べる列だけが違う

</details>

#### B_work AB列「差異_雇用区分」

- **何をするか**：Bの雇用区分コード（変換後）と、Aの雇用区分を比べる。違えば emp_type
- **使う関数**：IF、XLOOKUP

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(W2="","",IF(O2=XLOOKUP(W2,A_work!A:A,A_work!H:H,""),"","emp_type"))
```

Z列と同じ形

</details>

#### B_work AC列「差異_入社日」

- **何をするか**：利用開始日が「入社日の7日前〜入社日」の範囲なら一致、それ以外は hire_date
- **使う関数**：IF、AND

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(W2="","",IF(AND(R2<=Y2,R2>=Y2-7),"","hire_date"))
```

日付は内部では数値なので、引き算や大小比較ができる。Y-7 は入社日の7日前

</details>

#### B_work AD列「差異_在籍」

- **何をするか**：Aの在籍区分から「Bの有効はこうあるべき」（退職→0、在籍・休職→1）を作り、Bの有効と比べる
- **使う関数**：IF、XLOOKUP

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(W2="","",IF(IF(XLOOKUP(W2,A_work!A:A,A_work!G:G,"")="3","0","1")=G2,"","status"))
```

内側の IF で「あるべき値」を作る → 外側の IF でBの G列と比べる

</details>

#### B_work AE列「差異_社員番号」

- **何をするか**：Bの社員番号（6桁にそろえた後）が、結合先の社員番号と違えば emp_no（空欄・旧番号）
- **使う関数**：IF

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(W2="","",IF(I2=W2,"","emp_no"))
```

先頭ゼロの消失は I列でそろえているので、ここでは差異にならない

</details>

#### B_work AF列「Bのみ」

- **何をするか**：Aのどの社員にも結合しなかったアカウントに b_only の印を付ける
- **使う関数**：IF

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(W2="","b_only","")
```

結合先 W が空欄なら印を付ける

</details>

### 段階6　Aのみを見つける（A_work R〜S列）

B_work の W列（結合先）が全行できてから入力します。COUNTIF で「Bから何回結合されたか」を数えます。

#### A_work R列「Bの結合数」

- **何をするか**：この社員を結合先にしたBのアカウントが何件あるかを数える（B_work の結合先を作った後に入力する）
- **使う関数**：COUNTIF
- **注意**：0なら「Bに相手がいない」、2以上なら「1人に2つのアカウント」の疑い

<details><summary>答えの数式と、構文の読み方</summary>

```text
=COUNTIF(B_work!W:W,A2)
```

COUNTIF(範囲, 条件) は、範囲の中で条件に一致するセルの数を返す。B_work!W:W は別シートのW列全体

</details>

#### A_work S列「Aのみ」

- **何をするか**：突合対象なのにBに相手がいない社員に a_only の印を付ける
- **使う関数**：IF、AND

<details><summary>答えの数式と、構文の読み方</summary>

```text
=IF(AND(O2="対象",R2=0),"a_only","")
```

AND で「対象である」かつ「結合数が0」→ IF で印を付ける。"" は空欄（何も表示しない）

</details>

## 5. 確かめ方（数式を入れたあとに必ずやる）

| 確かめること | 数式（空いているセルに入れる） | 期待する結果 |
|---|---|---|
| 変換表の漏れ | `=COUNTIF(B_work!M:M,"★未登録")` と `=COUNTIF(B_work!O:O,"★未登録")` | どちらも 0 |
| 結合できなかったアカウント | `=COUNTIF(B_work!AF:AF,"b_only")` | 数件（テスト用・共用アカウント） |
| 同じ社員に2つのアカウント | `=COUNTIF(A_work!R:R,">1")` | 0（1以上なら、結合先の決め方を見直す） |
| 突合対象の人数 | `=COUNTIF(A_work!O:O,"対象")` | 約975人（役員・出向中・退職者を除く） |
| 差異の件数 | `=COUNTIF(B_work!Z:AE,"?*")` | 数十件（数百件なら、正規化が足りない） |

> `"?*"` は「1文字以上の何か」という意味の条件です（空欄を数えないため）。

## 6. 提出シートを作る

フィルタ（データ → フィルタ）で絞り込み、**「値として貼り付け」** します（数式のまま貼ると、元の行がずれたときに壊れます）。

| 作るもの | やり方 |
|---|---|
| matches | B_work で W列（結合先）が空欄でない行に絞り込み、W列を a_emp_id、A列（ユーザーID）を b_user_id に貼る |
| diffs（項目の差異） | B_work の Z〜AE列を1列ずつ、空欄でない行に絞り込み、W列・A列・その列の値を a_emp_id・b_user_id・item に貼る |
| diffs（Bのみ） | B_work の AF列が b_only の行を絞り込み、A列を b_user_id に、b_only を item に貼る（a_emp_id は空欄） |
| diffs（Aのみ） | A_work の S列が a_only の行を絞り込み、A列を a_emp_id に、a_only を item に貼る（b_user_id は空欄） |

保存したら、PCで採点します。

```bash
python tools/score_recon.py --xlsx data/ab/training_workbook.xlsx --log
```

## 7. よくあるエラーと直し方

| 表示 | 原因 | 直し方 |
|---|---|---|
| `#NAME?` | 関数名の打ち間違い。または古いExcelで XLOOKUP が使えない | 綴りを確認。古いExcelなら `IFERROR(INDEX(返す範囲,MATCH(探す値,探す範囲,0)),"★未登録")` で代用 |
| `#VALUE!`（R列） | DATEVALUE が日付として読めない文字列がある | その行の F列を見る。新しい形式なら、P〜R列の数式を見直す |
| `#VALUE!`（Q列） | 和暦なのに . がない、などの想定外の形式 | 元の値を確認し、判断台帳に記録する |
| 46143 のような数字 | 日付が数値のまま表示されている（中身は正しい） | セルの表示形式を「日付」にする |
| 社員番号が 881 になる | セルが数値として扱われ、先頭ゼロが消えた | 受領データは文字列のまま扱う。I列のように `RIGHT("000000"&…,6)` でそろえる |
| 全員「対象外」になる | `G2=1` のように、文字列を数値と比べている | `G2="1"` と二重引用符で囲む |
| 差異が数百件出る | 正規化が足りない（空白・異体字・変換表の漏れ） | 段階5の列を1つずつフィルタして、何が違うのかを目で見る |
| ★未登録 が残る | 変換表にない部署名・ラベルがある | map_dept・map_type に1行足す。推測で組織を決めず、組織マスタ（org_raw）で確認する |
