# learning/ ― あなたの学習記録

| ファイル | 役割 |
|---|---|
| `starter_recon.py` | 突合のスターターコード（わざと素朴）。これを改良していく |
| `decision_ledger.csv` | 判断台帳。迷った判断を1件1行で記録する |
| `data_dictionary.md` | データ辞書。出会った制度・列の意味を自分の言葉で書く |
| `weekly_log.md` | 週次振り返り |
| `score_log.csv` | 採点ログ（`python tools/score_recon.py --log` で自動追記） |
| `output/` | 突合結果の出力先（Git管理外） |

進め方は [`docs/02_how_to_train.md`](../docs/02_how_to_train.md) を参照してください。
